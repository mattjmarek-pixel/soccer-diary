## 3. Add diary_entries table to the database schema

In `shared/schema.ts`, add a `diaryEntries` table using Drizzle ORM:

```ts
import { pgTable, uuid, text, integer, timestamp, jsonb } from 'drizzle-orm/pg-core';

export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  appleId: text('apple_id').unique(),
  googleId: text('google_id').unique(),
  email: text('email'),
  name: text('name'),
  avatarUrl: text('avatar_url'),
  team: text('team'),
  position: text('position'),
  preferredFoot: text('preferred_foot'),
  age: integer('age'),
  createdAt: timestamp('created_at').defaultNow(),
});

export const diaryEntries = pgTable('diary_entries', {
  id: uuid('id').primaryKey().defaultRandom(),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  date: text('date').notNull(), // ISO date string e.g. "2026-05-03"
  mood: integer('mood').notNull(), // 1-5
  durationMinutes: integer('duration_minutes').notNull(),
  notes: text('notes'),
  skills: jsonb('skills'), // array of { name: string, notes: string }
  mediaUrls: jsonb('media_urls'), // array of strings
  createdAt: timestamp('created_at').defaultNow(),
  updatedAt: timestamp('updated_at').defaultNow(),
});
```

Replace any existing users table definition with this updated one. Run `npm run db:push` to apply to the database.

## 6. Implement real authentication with Apple Sign-In

The app currently uses fake simulated auth stored in AsyncStorage. Replace it with real Apple Sign-In on iOS.

### Server side
In `server/routes.ts`, add:
- `POST /api/auth/apple` — accepts `{ identityToken, fullName }` in the body
  - Verify the Apple identity token using the `apple-signin-auth` npm package (add it to dependencies)
  - Extract the `sub` (Apple user ID) and `email` from the verified token
  - Upsert a user in the `users` table based on `appleId`
  - Return a signed JWT using the `jsonwebtoken` npm package (add it). Sign with a `JWT_SECRET` environment variable. Include `{ userId, email }` in the payload. Token should expire in 30 days.

In `server/index.ts`, add JWT middleware:
- Create a middleware `requireAuth` that reads the `Authorization: Bearer <token>` header, verifies with `JWT_SECRET`, and attaches `req.userId` to the request
- Apply `requireAuth` to all `/api/entries` routes

### Client side
In `client/context/AuthContext.tsx`:
- Remove the simulated AsyncStorage auth logic
- Use `expo-apple-authentication` to trigger Apple Sign-In
- On success, send the `identityToken` and `fullName` to `POST /api/auth/apple`
- Store the returned JWT in AsyncStorage under the key `auth_token`
- On app load, check if a valid JWT exists in AsyncStorage and restore the session
- On logout, delete the JWT from AsyncStorage
- Provide `userId`, `userToken`, `signInWithApple`, and `signOut` from the context
- Send `Authorization: Bearer <token>` on every API request (update all fetch calls in DiaryContext to include this header)

Update `app.json` to ensure `expo-apple-authentication` plugin is listed (it already is).
